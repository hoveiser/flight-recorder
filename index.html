CONSENSUS / 0.6

Evidence is hashed off-chain. Decisions are finalized on GenLayer.

01 / PROBLEM

When agents disagree,
evidence should speak.

Agent-to-agent work produces a trail of requests, responses, deliveries, and validations. Without a neutral record, a dispute becomes a contest of stories.

02 / ARCHITECTURE

Two layers.
One accountable flow.

Off-chain / witness

Flight Recorder keeps an append-only SQLite log. Every event joins a SHA-256 hash chain, then exports a verifiable case file for adjudication.

On-chain / judge

Settlement locks escrow, anchors milestones, and uses GenLayer validator consensus to inspect evidence and resolve the deal.

03 / FEATURES

Built for the
moment of truth.

Hash-chained logs

Detect tampering, missing events, and broken history before evidence reaches the chain.

AI adjudication

Let GenLayer validators weigh a case file through an equivalence-principle workflow.

Escrow lifecycle

Fund, dispute, resolve, appeal, and finalize with explicit on-chain state transitions.

04 / QUICK START

From log to
verdict.

Install the service

Set up Python dependencies with pip install -r requirements.txt.

Run the recorder

Start the API with uvicorn src.main:app --reload and capture the evidence trail.

Test the settlement

Run pytest tests/direct/test_settlement.py -v for the five direct-mode contract tests.
